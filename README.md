# Spotify-Like Java App

A text-based music application developed for my Intro to Java course. The program allows users to browse a music library, search for songs, and play local audio files.

## Features

- Menu-driven interface with Home, Search, Library, and Quit options
- Search for songs by title
- Browse songs and view their information
- Load music data from a JSON file using Gson
- Play local WAV audio files

## Technologies Used

- Java
- JSON / Gson
- Maven
- Java Sound API

## About the Project

This project helped me practice Java programming, working with data structures, handling user input, and reading external files.

Developed using instructor-provided starter code, which I extended with additional application functionality.
